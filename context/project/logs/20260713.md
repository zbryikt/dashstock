# 2026-07-13 工作記錄

## 專案：dashstock — 股市 K 線看盤工具


## 主要完成項目

### 1. LocalStorage 持久化股票清單

`addSym()` 與 `removeSym()` 時呼叫 `saveSyms()`，將 symbol 清單寫入 `localStorage`（key: `dashstock-syms`）。啟動時讀回，若無紀錄則預設載入 `2330.TW`。


### 2. Chip click 切換 dim / active

compare mode（≥2 股）時，點擊股票 chip 的 label 區域（非 × 按鈕）可切換該 series 的 dim 狀態：

 - `dimMap[sym]` 追蹤各股 dim 狀態
 - dim 時：series color 換成 `hexToRgba(color, 0.2)`，lineWidth 縮為 1
 - chip 本身加 `.dim` class（`opacity: 0.35`，含 transition）
 - `applyDimStates()` 集中管理所有 series 的顯示狀態，在 `loadCompare`、`loadMoreCompare`、`redrawCompare` 後均會呼叫


### 3. Shift+drag 橫向選取區間，顯示漲跌幅

Shift + 滑鼠拖曳圖表時：

 - 暫時停用 chart 的 `pressedMouseMove`（防止 chart 自行 pan）
 - 顯示半透明藍色 overlay（`#shift-overlay`，`position: absolute` in `.chart-area`）
 - mouseup 後呼叫 `showShiftResult()`：用 `series.dataByIndex(logicalIndex, ±1)` 取兩端 bar，查 `cmpDataMap` / `allData` 計算漲跌幅，結果顯示在 `#shift-result`（圖表底部中央）
 - 不帶 Shift 直接點圖表清除選區；切換 range / symbol 也自動清除


### 4. Shift+hover 各 line 虛線跟隨滑鼠

compare mode 下 Shift + 滑鼠移動（非 drag 狀態）時：

 - 用 `chartInstance.timeScale().coordinateToLogical(x)` 取 logical index
 - 對每條 series 呼叫 `series.dataByIndex(Math.round(logIdx))` 取當前 x 的值
 - 用 `series.createPriceLine({lineStyle: LightweightCharts.LineStyle.Dashed, ...})` 建立虛線
 - 後續移動只呼叫 `priceLine.applyOptions({price: newValue})` 更新（避免重複建立）
 - dim 的 series 虛線顏色同步 fade（`hexToRgba(color, 0.2)`）
 - 滑鼠離開圖表、放開 Shift、切換資料時呼叫 `removeShiftPriceLines()` 清除
