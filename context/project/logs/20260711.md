## 主要完成項目

### 1. 修正多股比較模式 lazy load bug
- **問題**：compare mode 兩檔股票同時往左捲動，只有一檔的資料會更新
- **原因**：race condition — `Promise.all` 回來後先把 `isLoadingMoreCmp = false` 清掉，再 forEach 更新各股資料。第一檔 `setData()` 觸發 `subscribeVisibleLogicalRangeChange`，此時 flag 已清，立刻跑第二次 `loadMoreCompare()`。這次抓到的是舊的 `cmpFromMap['第二檔']`（第一輪 forEach 還沒跑到），但等第二次 request 回來時，`cmpFromMap['第二檔']` 已被第一輪更新為更早的日期，filter 比對失敗 → `cmpNoMoreMap['第二檔'] = true` 被提早設定。
- **修法**（`web/src/pug/index.pug`）：
  1. 在 `toLoad.map()` 建 request 時先 capture `fromTime = cmpFromMap[s.sym]`，透過 result 物件傳進 forEach
  2. filter 改用 `r.fromTime`（快照值）而非 `cmpFromMap[r.sym]`（可能已被改動）
  3. `isLoadingMoreCmp = false` 移到 forEach **之後**，防止 setData 觸發重入

### 2. 股票代號搜尋 autocomplete
- 前端搜尋框打字時顯示下拉選單（代號 + 中文名）
- **後端**（`api/index.ls`）：新增 `/api/search?q=` endpoint，使用 `yf.search()`
- **前端**（`web/src/pug/index.pug`）：
  - `position: fixed` 下拉選單，JS 計算位置，可跳出 overflow 容器
  - debounce 250ms，避免打字時大量請求
  - 鍵盤操作：↑↓ 選項、Enter 選取、Escape 關閉
  - 點選或 Enter 自動加入股票

### 3. 中文名稱搜尋（TWSE 本地清單）
- **問題**：Yahoo Finance `/v1/finance/search` 不支援中文 query，回傳 `Invalid Search Query`
- **解法**：
  - 後端啟動時從 TWSE Open API 拉取上市（`.TW`）與上櫃（`.TWO`）股票清單
  - 記憶體 + 磁碟雙層 cache（`data/tw-stocks.json`），TTL 24h，重開 server 不用重抓
  - query 含中文 → 只搜本地清單（即時，毫秒級）；英文/數字 → 本地 + Yahoo 合併結果

### 4. Chip hover 切換報價顯示
- 左側股票 tag（chip）滑鼠移入時，右側 topbar 報價切換為該股票資訊
- `loadQuote()` 拆成 `displayQuote(data)` + fetch，加入 `quoteCache` 做 session-level cache，避免重複打 API

### 5. 歷史資料磁碟 cache
- lazy load 的歷史 chunk（`before` + `interval` 請求）資料固定不變，永久 cache 到 `data/` 目錄
- 檔名格式：`{symbol}_{interval}_{period1}_{period2}.json`
- cache hit 約 2ms（vs Yahoo API 約 250ms）
- 初始 range 請求（含今日最新資料）不 cache

### 6. 修正 5D 無資料 + 1D 無法往回拉
- **5D 問題**：`15m` interval 每天有多筆資料，沿用 date string 格式（`YYYY-MM-DD`）導致同一天重複 key，`lightweight-charts` 無法 render
- **1D 往回拉問題**：
  1. 前端 `loadMore()` 有 `if (isIntraday) return` 擋住
  2. 後端 `before` 參數只支援 ISO date string，不支援 Unix timestamp
- **修法**：
  - 後端：`sub-daily = ['5m','15m','30m','1h']`，這類 interval 自動改用 Unix timestamp 格式；`before` 純數字 → 視為 Unix timestamp，不多扣一天，用嚴格 `<` 過濾；`chunk-days` 對 5m=7天、15m=14天
  - 前端：移除 `isIntraday` flag，`loadMore()` 改用 `isLoadingMore || noMoreHistory` guard，所有 interval 均支援 lazy load
