# 2026-07-21 工作記錄

## 專案：dashstock — 股市 K 線看盤工具


## 主要完成項目

### 1. Shift+hover tooltip 顯示實際收盤價

compare mode 下 Shift + 滑鼠移動時，各 series 雖已有虛線跟隨，但 price line 的軸標籤顯示的是正規化後的 % 值。改為：

 - price line 自身 `axisLabelVisible: false`，不在 y 軸顯示
 - 新增 `#shift-hover-tooltip`（HTML overlay，`position: absolute; pointer-events: none`）
 - `updateShiftHoverTooltip(mouseX, mouseY)` 查 `cmpDataMap` 取原始 close 價，每股一行，靠滑鼠右側顯示（靠近右緣時自動翻左）
 - 滑鼠離開或放開 Shift 時 `hideShiftHoverTooltip()`

### 2. Compare mode dblclick 重設比較基準點

雙擊圖表（非 shift dblclick）時，以點擊處的 x 座標為新的比較原點：

 - `coordinateToLogical(e.clientX - rect.left)` 取 logical index
 - 對每個 symbol 用 `series.dataByIndex(Math.round(logIdx), -1)` 取最近的 bar
 - 再用 `findBarByTime(cmpDataMap[sym], bar.time)` 取原始 close
 - 更新 `cmpBaseMap[sym]`，呼叫 `redrawCompare()` 重繪


### 3. 多股 localStorage 還原只顯示一組（batch init fix）

**原問題**：從 localStorage 讀回多個 symbol 後，逐一呼叫 `addSym()`，每次都觸發 `reload()`，後者每次都重設 `cmpDataMap` / `cmpSeriesMap`，最終只剩最後一股的資料。

**修法**：init IIFE 改為先 batch push 所有 symbol 到 `symbols` 陣列，最後只呼叫一次 `reload()`。


### 4. LightweightCharts defer 問題修正

**原問題**：`loadCompare()` → `initChart()` 在 inline `<script>` 執行時同步呼叫。`lightweight-charts` 的 `<script>` 帶 `defer`，defer script 在 DOM fully parsed 後才執行，但 inline script 在 body 底部就執行 → `LightweightCharts` 此時還未定義，頁面載入後圖表空白。

**修法**：`if (!chartInstance) initChart()` 移入 `loadCompare()` 的 `Promise.all.then()` callback 內（非同步，此時 defer script 已執行完畢）。


### 5. 選股集（stock group）管理 UI

在 sym-bar 前加入選股集下拉選單：

 - 狀態：`groups = [{id, name, syms}]`、`currentGroupId`
 - localStorage key 改為 `dashstock-groups` + `dashstock-current-group`；自動 migrate 舊 `dashstock-syms`
 - 下拉選單（`#group-dropdown`，`position: fixed`）：列出所有集合，點選切換，inline rename（input + ✓/✗）、inline delete confirm（確定/取消）、新增集合（輸入名稱）
 - `syncSymbolsToGroup()` 在 `addSym()` / `removeSym()` / `switchGroup()` 時同步當前 group 的 syms
 - `switchGroup(id)` 切換時清空現有 series + dimMap，從新 group 的 syms 重載


### 6. Shift+drag 漲跌 panel 改版

 - **時間區間 header**：panel 頂端新增一行 `YYYY/MM/DD – YYYY/MM/DD`（`fmtBarTime()` 格式化）
 - **位置**：從 `bottom: 12px` 改為 `top: 44px`（圖表上緣下方），避免遮住 x 軸


### 7. CPER 往左拉缺值 fix

**問題**：`loadMoreCompare` 完成後 `setData()` 可能觸發不到 `subscribeVisibleLogicalRangeChange`（已在 5 格以外），若 viewport 仍需更多資料，後續再也沒有 trigger 載入。

**修法**：`loadMoreCompare` 的 `.then()` 尾端加 `setTimeout(fn, 50)`，50ms 後檢查 `range.from < 5`，若仍在邊界則重觸一次 `loadMoreCompare()`。


### 8. 刪除後新增顏色重複 fix

`COLORS[symbols.length % COLORS.length]` 依當前數量取色，刪掉一股再加入時可能取到已在用的顏色。

**修法**：新增 `pickColor()`，遍歷 `COLORS` 陣列找第一個未被現有 symbol 使用的顏色；全佔滿才 fallback 到模運算。


### 9. CPER 快速往左拉變垂直直線 fix（race condition）

**根本原因**：

1. 3M 狀態下往左 pan → `loadMoreCompare` fetch 發出（`r.fromTime` = 3M 起始點，約 4 月）
2. 使用者點 6M → `loadCompare` 同步 reset `cmpDataMap = {}`，接著 fetch 6M 資料
3. 6M fetch 先完成，`cmpDataMap[CPER]` = 6M 資料（1月–7月）
4. 舊 `loadMoreCompare` fetch 才回來，`fresh` = 4月以前的資料（1月–3月）
5. `fresh.concat(cmpDataMap[CPER])` → 1月–3月出現兩次，時間重複
6. `setData` 傳入重複時間點 → lightweight-charts 渲染垂直線

**修法**：三層防護：

 1. **generation counter**：`cmpGeneration` 在每次 `loadCompare` 遞增；`loadMoreCompare` 捕捉呼叫當下的 `gen`，callback 執行時若 `gen !== cmpGeneration` 直接 bail out
 2. **dedup by time**：sort 後 `merged.filter((d,i) => i===0 || d.time !== merged[i-1].time)` 去除相鄰重複 time
 3. **null-safe concat**：`cmpDataMap[r.sym] || []`，防止 reset 後 concat undefined
